GitHub Pages ＆ Firebase 設置手順

⚠️ 重要：Googleログインの承認済みドメイン追加 GitHub Pagesで公開した後、Googleログインを動かすにはFirebaseコンソールでのドメイン許可が必要です。
  1. GitHub Pagesにアップロード:
    このファイルを index.html という名前で保存し、GitHubリポジトリのルート（mainブランチ）へプッシュします。
  2. Pagesの設定を有効化:
    GitHubリポジトリの Settings > Pages で Deploy from a branch (main / root) を選択して保存します。
  3. Firebaseにドメインを追加:
    Firebase Console > Authentication > Settings > 「承認済みドメイン」に、あなたのGitHub Pagesドメイン（例: username.github.io）を追加してください。
