GitHub Pages & Googleログインの設定ガイド

⚠️ 重要: Googleログインの承認済みドメイン追加 GitHub Pagesで公開した後、Googleログインエラー（auth/unauthorized-domain）を防ぐにはFirebaseへのドメイン登録が必要です。
  1. ファイル名を設定:
    このコードを index.html として保存し、GitHubリポジトリのルートにコミット・プッシュします。
  2. GitHub Pagesを有効化:
    GitHubリポジトリの [Settings] > [Pages] で Source を Deploy from a branch に設定し、main ブランチの / (root) を選択します。
  3. Firebaseにドメインを追加:
    Firebase Console にアクセスし、
    [Authentication] > [設定] > [承認済みドメイン] に、お使いのGitHub Pagesドメイン（例: username.github.io）を追加してください。
